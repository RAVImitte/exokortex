# ExoKortex

ExoKortex watches your software and AI project repositories, notices meaningful changes, and keeps your portfolio up to date, using your own LLM API key.

The project is being bootstrapped. The founding brief is in [docs/product/bootstrap-brief.md](docs/product/bootstrap-brief.md). The stack and why each part is there are in [docs/architecture/tech-stack.md](docs/architecture/tech-stack.md).
